## 🔄 Manutenção da Documentação

### Quando Atualizar

**README.md**:
- Nova funcionalidade importante
- Mudança na stack tecnológica
- Nova versão major/minor

**DOCUMENTACAO_COMPLETA.md**:
- Mudanças na arquitetura
- Novos endpoints
- Novas tabelas no banco

**.agent/skill/tarifaZero.md**:
- Mudanças significativas no projeto
- Novos padrões ou regras
- Troubleshooting adicional

**GERENCIAMENTO_VERSOES.md**:
- Mudanças no processo de release
- Novos tipos de versão

### Como Atualizar

1. Edite o arquivo correspondente
2. Atualize a data de "Última Atualização"
3. Commit com mensagem: `docs: atualiza [nome do arquivo]`
4. Push para o repositório
